# Demo walkthrough and recording script

Target: under three minutes. Capture actual application behavior only. Do not record secrets, private environment files, real buyer credentials or unrelated user data. Use 1440px desktop recording; keep text readable and avoid spending time typing long briefs. Prepare local users/project beforehand and verify every demonstrated action.

## Preparation

Run the README setup/migration/seed commands. For the quickest walkthrough, select **Try the demo without an account** on the landing or sign-in page. It creates a private persistent workspace with a $600 sample project and $150/$250/$200 milestones. Use **Switch to freelancer/client view** in the sidebar to act as either participant in the same workspace. Return in the same browser to continue. Clearing browser cookies/site data removes access; demo workspaces are not automatically deleted. Alternatively, use the documented local accounts or create a fresh client/freelancer pair; seed does not reset existing progress.

For an AI-planning demonstration create a fresh project with no saved milestones. Real mode must be configured and verified before describing it as real AI. Otherwise show the SIMULATED MOCK AI label and state it explicitly. Configure and actually accept a Sandbox checkout before including a successful capture in the recording. Automated checkout fixtures are not valid transaction footage.

## Recovery and truthful alternatives

In the account-free demo, AI is always simulated and labeled; do not describe it as a live model response. Role switching shares only that visitor's workspace. Checkout is intentionally disabled for demo users; use a separately authenticated account and verified Sandbox buyer approval before claiming a successful transaction. Do not use a fabricated receipt, edit a database into PAID, or splice controlled test footage into a claimed live transaction. A demo without live Sandbox acceptance does not satisfy the final integration gate.

Save screenshots of dashboard, editable proposal/mode label, evidence/revision, report limitations, human decision, real verified Sandbox receipt (only when available), and audit history. Record with an OS screen recorder, trim to less than three minutes, review for secrets and accuracy, upload to a human-owned public YouTube account, and add the actual link to DEVPOST.md. A local recording is available at `docs/videos/veriflow-demo.mp4`; review it for secrets and accuracy before publishing. It has not been uploaded.
